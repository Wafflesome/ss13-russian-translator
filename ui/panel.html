What you type

Write in English in the say box (T, Y, O, M… or whatever keys you have set), the input bar at the bottom and other one-line boxes. It is sent in Russian.

Enter turns your English into Russian (green outline). Press Enter again to send it.

When you write about yourself, the Russian uses your gender: “I'm tired” is sent as я устал. Words about other people are left alone.

MaleFemale

How you know it worked: the say box shows a green EN→RU mark while this is on, and when your message comes back in chat a green line under it shows the Russian that was sent. It is also listed under “What you sent” below.

Translation services

Google is free. DeepL needs your own API key.

The server asks for literate Russian. Google "Best" or DeepL both work.

Best uses the translator of the Google Translate website (better sentences); if it doesn't answer quickly the classic one is used, so it is never slower.

Only needed if you pick DeepL.

Game dictionary

Game words (blob, changeling, item and job names…) are translated the way the server names them: from the SS220 wiki, the server's own item names, and data/lexicon_game.json (yours to edit).
